# Hasil perhitungan

CLI, batch, contoh Excel dan studi menulis hasil baru ke direktori ini.
Hasil lama dari `Core/output/` dipindahkan ke direktori ini.
File hasil serta provenance atmosfer diabaikan Git; README ini tetap dilacak.

Artefak penelitian yang sudah didokumentasikan berada di `validation/`.
Konfigurasi baseline dan waktu pembuatan pada provenance hasil lama tetap
berlaku; menjalankan program dengan `F=2.0` menghasilkan evaluasi baru.

Label dengan karakter rusak pada tiga workbook lama sudah diperbaiki
tanpa mengubah angka atau formatnya. Enam grafik lama dibuat ulang dari
data workbook tersimpan, tanpa menghitung ulang cuaca atau model.
Salinan sebelum perbaikan berada di `.cache/encoding-repair/original-outputs/`.
